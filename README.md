# Sprachstufe

A full-stack language-learning platform: register, learn German or French from
A1 to C1, chat with an AI tutor, take mock exams modeled on Goethe-Institut,
telc, TestDaF, and DELF, and earn Sprachstufe practice certificates as PDFs.

This is real, runnable code — not a mockup. It's been tested end-to-end
against a live PostgreSQL database and a live React dev server.

## Stack

- **Backend:** Node.js + Express + PostgreSQL (`pg`), JWT auth, PDFKit for
  certificates, Claude API for the chat tutor.
- **Frontend:** React + Vite.
- **Database:** PostgreSQL — built for Supabase or Neon's free tier.

## Important note on certificates

Certificates generated by this app are **Sprachstufe's own practice
certificates**. They are clearly labeled as such and state they are not
official credentials. They model the format of Goethe-Institut, telc,
TestDaF, and DELF exams for practice purposes only. To get an official,
internationally recognized credential, a learner needs to register for a
proctored exam through the relevant institution directly.

## 1. Set up the database (Supabase or Neon)

Pick one — both have generous free tiers:

**Supabase:** create a project at supabase.com → Project Settings → Database
→ Connection string → URI. Copy it.

**Neon:** create a project at neon.tech → Dashboard → Connection Details →
copy the connection string.

You'll get something like:
```
postgresql://user:password@host:5432/dbname?sslmode=require
```

## 2. Backend setup

```bash
cd backend
npm install
cp .env.example .env
```

Edit `.env`:
- `DATABASE_URL` — paste your Supabase/Neon connection string
- `JWT_SECRET` — any long random string (e.g. run `openssl rand -hex 32`)
- `ANTHROPIC_API_KEY` — your key from console.anthropic.com (for the chat tutor)

Then seed the database (creates tables + sample German/French courses and exams):
```bash
npm run seed
```

Start the backend:
```bash
npm run dev
```
It runs on http://localhost:4000 by default.

## 3. Frontend setup

```bash
cd frontend
npm install
npm run dev
```
It runs on http://localhost:5173 and proxies `/api/*` to the backend automatically.

Open http://localhost:5173, register an account, and you're in.

## 4. Deploying for real

- **Backend:** Render, Railway, or Fly.io all work well for an Express app.
  Set the same environment variables there as in your local `.env`.
- **Frontend:** Vercel or Netlify for the Vite build (`npm run build` → deploy
  the `dist/` folder), or serve it from the same host as the backend.
- Update `VITE_API_URL` in the frontend's environment if your backend isn't
  on the same domain (see `frontend/src/api.js`).
- The backend currently allows requests from any origin (`cors()` with no
  restrictions) so it's easy to get running. Before going live, restrict this
  to your actual frontend domain — in `backend/server.js`, change
  `app.use(cors())` to `app.use(cors({ origin: 'https://yourdomain.com' }))`.

## 5. Before taking real money

The `/api/billing/upgrade` endpoint currently grants Premium instantly with no
payment — it's a placeholder so you can test the premium-gated content. Swap
it for a real Stripe Checkout + webhook flow before launching publicly.

## Project structure

```
  db/database.js       Postgres connection + schema
  db/seed.js            Sample course/exam content
  middleware/auth.js    JWT auth middleware
  routes/auth.js        Register / login / me
  routes/courses.js     Tracks, levels, lessons, progress, scoring
  routes/exams.js        Mock exam listing, taking, scoring
  routes/certificates.js PDF certificate generation
  routes/chat.js         AI tutor chat (Claude API)
  routes/billing.js      Premium upgrade/cancel (placeholder)
  utils/tokens.js        Shared JWT signing helpers
  server.js              Express app entry point

frontend/
  src/api.js             API client
  src/AuthContext.jsx    Auth state management
  src/App.jsx            Main app shell / tab routing
  src/components/        All UI components
```
